Документация

Terra API.

Годовые карты поверхности по данным Sentinel-2.

Изменение леса

POST /api/v1/forest

JSON: bbox, before_date и after_date. Снимки Landsat или Sentinel-2 подбираются автоматически около указанных дат. Возвращаются площади, NDVI, метаданные сцен и ссылки на изображения. Точность модели вне Японии не проверена.

Даты съёмки

GET /api/v1/scenes?bbox=[west,south,east,north]&year=2023

Даты доступных сцен для области и года. Облачность относится ко всей сцене.

Каталог

GET /api/v1/catalog

Доступные годы и категории анализа.

Покрытие по датам

POST /api/v2/cover

JSON: bbox, before_date, необязательная after_date и categories. Снимки Sentinel-2 L1C с 2017 года. Возвращаются фактические даты сцен. Даты до 2017 года пока недоступны для покрытия.

curl -X POST http://localhost:3187/api/v2/cover -H "Content-Type: application/json" -d '{"bbox":[65.46,44.84,65.465,44.845],"before_date":"2023-07-09","after_date":"2026-07-01","categories":["trees","water"]}'

Годовой анализ

POST /api/v1/analyze

JSON-запрос. Координаты — WGS84: запад, юг, восток, север. При отсутствии compare_year анализируется один год.

curl -X POST http://localhost:3187/api/v1/analyze \
  -H "Content-Type: application/json" \
  -d '{"bbox":[141.94,42.75,141.95,42.76],"year":2022,"compare_year":2023,"categories":["trees","water","forest_loss"]}'
ПараметрОписание
bboxКоординаты выбранного прямоугольника
yearПервый год: 2017–2023
compare_yearВторой год, необязательно
categoriesСписок идентификаторов из каталога

Ответ содержит площадь, долю доступных данных, результаты по выбранным классам, источник и ссылку на GeoTIFF. Потеря и появление деревьев доступны только для сравнения.

Данные: Impact Observatory / Esri Annual Land Cover. Используются готовые результаты глобальной нейросети по Sentinel-2. Это годовые карты, а не классификация отдельного снимка по заданной дате. Площадь и изменения являются оценками.

Схема API: OpenAPI.
